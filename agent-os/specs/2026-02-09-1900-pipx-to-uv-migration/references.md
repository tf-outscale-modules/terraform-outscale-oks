# References: Migrate from pipx to uv for oks-cli installation

## Mise Documentation

- [Mise pipx backend](https://mise.jdx.dev/dev-tools/backends/pipx.html) — Documents how the `pipx:` backend works and its default behavior of using `uvx` when uv is available.
- [Mise tools configuration](https://mise.jdx.dev/dev-tools/) — General documentation on configuring tools in `mise.toml`.

## uv

- [uv documentation](https://docs.astral.sh/uv/) — The fast Python package installer and resolver.
- [uvx](https://docs.astral.sh/uv/guides/tools/) — uv's tool execution command, equivalent to `pipx run`.
